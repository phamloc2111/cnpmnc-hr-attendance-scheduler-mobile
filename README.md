# HR Attendance Mobile

The Flutter mobile application for the HR Attendance system.

## Requirements

- Flutter SDK 3.38 or later
- Dart 3.10 or later
- Android Studio or an Android device/emulator for Android development
- Xcode on macOS for iOS development

## Run the Application

```powershell
cd mobile
flutter pub get
flutter run
```

To target an available Android or iOS device, run:

```powershell
flutter devices
flutter run -d <device-id>
```
